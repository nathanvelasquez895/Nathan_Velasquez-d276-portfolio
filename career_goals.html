My Evolution in Web Development: From AI Engine to Custom Site

My journey into web development started with a real-world problem I needed to solve before taking Discrete Mathematics II. To prepare for the course, I took on the role of project manager, QA tester, and code debugger to build a browser-based study GUI powered by a library of nearly 500 custom AI prompt templates. Working directly with LLM-generated code meant spending hundreds of hours inspecting HTML containers, debugging broken JavaScript logic, and refining UI layouts to ensure the system functioned reliably.

That hands-on experience sparked a drive to build web applications completely from scratch with my own hands. After formalizing my understanding through WGU’s Web Development Foundations course, I put the AI generators aside and hand-coded this entire portfolio site using raw HTML5, CSS3, and JavaScript.

Building this platform gave me total control over every element of the user experience:

  • From Debugger to Architect: Transitioning from auditing generated code to writing structured, semantic HTML markup and scalable CSS rules from the ground up.
  • Custom Responsive UI: Engineering fluid layouts using flexbox, custom media queries, and absolute positioning to guarantee smooth mobile-to-desktop responsiveness without relying on third-party frameworks.
  • Clean Asset Integration: Implementing custom SVG bullet structures, HTML5 media elements, and styled contact forms designed to load quickly and maintain a sharp visual hierarchy.
