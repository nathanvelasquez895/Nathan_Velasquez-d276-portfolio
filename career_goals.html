My Evolution From AI-generated Code Auditor, To Handwriting A Full Website

My journey into web development didn't start as just an interest; it began as what I saw as a necessity for learning complex math concepts. I found that my learning style excelled with the use of AI technology; however, my project soon became impossible to manage. Starting with just a .txt document containing every prompt, I immediately saw that a solution was needed to avoid editing dozens (or eventually hundreds) of prompts if a single change to the prompt template was required. That's what began my journey of using Claud to help code my prompt library GUI, which separates content, templates, and GUI, optimizing each element individually.

This hands-on experience diving headfirst into web development gave me the drive to code this entire website by hand. I have now been able to formalize my understanding of HTML, CSS, and JavaScript through my Web Development course in college. I am learning that coding isn't as complex as it looks. In fact, compared to learning any other spoken language, I would say it's far easier, and I'm excited about my future in coding.

Some of my favorite learning experiences in creating this website were:

  • Transitioning From Debugger to Architect: From auditing LLM-generated code, to writing structured HTML markup and CSS rules from the ground up. Developing the ability to visualize exactly the code that goes into every website I now view.
  • Custom text animation: Utilizing "nth-child" pseudo-elements to give every letter a specific phase-in delay time. This creates the incremental appearance.
  • CSS customization: Implementing custom SVG bullet structures and heading design, HTML5 media elements to make mobile phone transitions seamless, and having full control of the "dark mode" design that many others and I find most appealing.
